I/ DE BAI YEU CAU:
 -> Đề bài toán yêu cầu xây dựng một hệ thống quản lý của hàng đồ 
 cổ(AntiqueShop) áp dụng hai tính cốt lỗi của lập trinh hướng đối 
 tượng OOP, đóng gói(encapsulation) và kế thừa Inheritance

 II/ PHÂN TÍCH BÀI TOÁN 
  ->  bối cảnh: cửa hàng bán các món đồ thuộc 3 loại chính
   + Bình cổ(vase)
   + Tượng cổ(Statue)
   + Tranh cổ(Painting)

  -> Yêu cầu: chủ cửa hàng có thể thêm các món đồ mới vào kho, 
  hiển thị danh sách, và tìm kiếm đồ cổ. Tất cả các đối tượng này 
  được quản lý tập  trung trong một mảng(Array)
  
  ** phân tích sơ đồ lơp chính **.
  1/ lớp cha:  Item
    # thuộc tính: 
        + id: string 
        + value: int 
        + creator: string 

    # method:
        + input
        + toString

   2/ các lớp con kế thừa: vase, statue, painting  
   3/ Lớp quản lý danh sách chứa đồ cổ Itemlist
        # thuộc tính 
            + list[]: mảng chứa các đối tượng kiểu item 
            + numOfItem: int số lượng đồ cổ hiện có 
            + Max: int = 100 sức chứa tối đa của mảng

        # Phương thức 
            + addItem: them mới món đồ
            + displayAll: duyệt mảng và in ra toàn bộ 
            + findItem: tìm kiếm món đồ theo tên, người tạo 
            + displayItemByType: hiển thị danh sách đồ cổ theo đúng phân loại    


    4/ Lớp AntiqueShop chứa hàm main và tạo menu chọn 
     + 1. thêm vase 
     + 2. thêm Statue 
     + 3. Thêm Painting 
     + 4. xem danh sách
