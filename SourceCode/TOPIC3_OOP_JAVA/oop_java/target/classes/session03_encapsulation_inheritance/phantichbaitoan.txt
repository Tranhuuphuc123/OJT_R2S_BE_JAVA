1. ĐỌC VÀ DIỄN GIẢI LẠI ĐỀ
    Bài tập yêu cầu xây dựng hệ thống quản lý cửa hàng đồ cổ (Antique Shop) ứng dụng 
    tính Đóng gói (Encapsulation) và Kế thừa (Inheritance):
    - Class cha `Item`: Chứa các thông tin chung của món đồ cổ (id, value, creator).
    - 3 Class con kế thừa từ `Item`:
    + `Vase` (Lọ hoa): Bổ sung height, material.
    + `Statue` (Tượng): Bổ sung weight, color.
    + `Painting` (Tranh): Bổ sung height, width, isWaterColor(mau nuoc), isFramed(khung dong).
    - Class `ItemList`: Quản lý danh sách các Item bằng mảng cố định (tối đa 100 phần tử), 
    thực hiện các chức năng: Thêm, Hiển thị tất cả, Tìm theo tác giả, Cập nhật theo ID, 
    Lọc theo loại (Vase/Statue/Painting).
    - Class `AntiqueShop`: Chứa hàm `main` hiển thị Menu tương tác với người dùng.

2. XÁC ĐỊNH INPUT, OUTPUT, CONSTRAINT
    - Input: Lựa chọn menu (1-7) và dữ liệu nhập từ bàn phím cho từng thuộc tính đồ cổ.
    - Output: Thông báo trạng thái, danh sách đồ cổ hiển thị theo định dạng chuỗi.
    - Constraints (Ràng buộc dữ liệu):
        + `id`: Không null, không rỗng và phải duy nhất trong mảng.
        + `value`: Phải >= 0.
        + `creator`: Không rỗng.
        + `height` (Vase/Painting): Trong khoảng [0, 2000].
        + `material` / `color`: Không rỗng.
        + `weight` (Statue): Trong khoảng [0, 1000].
        + `width` (Painting): Trong khoảng [0, 3000].
        + `MAX`: Mảng lưu tối đa 100 sản phẩm.

3. TẠO VÍ DỤ BẰNG TAY
    - Thêm Vase: ID="V01", Value=500, Creator="A", Height=150, Material="Ceramic".
     -> `numOfItem` = 1, `list[0]` lưu đối tượng Vase V01.
    - Thêm Statue: ID="S01", Value=1000, Creator="B", Weight=200, Color="Bronze".
     -> `numOfItem` = 2, `list[1]` lưu đối tượng Statue S01.
    - Tìm kiếm theo Creator "A" -> Trả về Vase V01.
    - Lọc theo loại "VASE" -> In ra danh sách các Vase trong mảng.

4. LIỆT KÊ EDGE CASES(Edge Case là những tình huống đặc biệt, cực đoan
    hoặc nằm ngay "ranh giới" của dữ liệu đầu vào)

    - Nhập khoảng trắng/rỗng cho các chuỗi -> Bắt buộc nhập lại.
    - Nhập giá trị số ngoài phạm vi (ví dụ: height = -10 hoặc height = 2500) -> Bắt nhập lại.
    - Trôi lệnh khi nhập `Scanner` chuyển từ số sang chuỗi -> Xử lý bằng 
    `Integer.parseInt(sc.nextLine())` hoặc `Boolean.parseBoolean()`.
    - Thêm mới khi mảng đầy (`numOfItem >= 100`) -> Báo lỗi và trả về `false`.
    - Cập nhật / Tìm kiếm trên mảng rỗng -> Báo thông báo phù hợp.


5. VIẾT GIẢI PHÁP ĐƠN GIẢN BẰNG PSEUDOCODE

        CLASS Item:
            FIELDS: protected id, creator (String), value (int)
            METHOD input(): Read and validate id, value, creator from Scanner.

        CLASS Vase EXTENDS Item:
            FIELDS: private height (int), material (String)
            METHOD input(): Super.input(), read & validate height (0..2000), material.

        CLASS ItemList:
            FIELDS: list[100] (Item), numOfItem = 0
            METHOD addItem(item):
                IF numOfItem >= 100 RETURN false
                list[numOfItem++] = item
                RETURN true
            METHOD findItem(creator):
                FOR i FROM 0 TO numOfItem - 1:
                    IF list[i].getCreator() EQUALS creator RETURN list[i]
                RETURN null

7. CHỨNG MINH NGẮN GỌN VÌ SAO GIẢI PHÁP ĐÚNG
    - Kế thừa (Inheritance): Tái sử dụng lại các thuộc tính chung (id, value, creator) từ `Item`,
    giúp code ngắn gọn, tránh lặp lại.
    - Đa hình (Polymorphism): Mảng `Item[]` chứa được cả `Vase`, `Statue`, `Painting`. Hàm `toString()` 
    và `input()` được ghi đè (Override) đúng theo loại đối tượng thực tế.

10. PHÂN TÍCH ĐỘ PHỨC TẠP
    - Time Complexity:
        + Thêm phần tử `addItem`: O(1).
        + Tìm kiếm / Lọc / Cập nhật: O(N) với N là số lượng món đồ cổ hiện có trong mảng.
    - Space Complexity: O(1) phụ thuộc mảng cố định 100 phần tử trên Memory Heap.
